# Codali default skill probes

These are development checks of skill discovery and workflow guidance, not a held-out intelligence benchmark or evidence for the +10% quality goal. Only real skill read tools were exposed in the bounded probe harness; host services and project mutations were not performed.

Run with `docdexd test run-node --repo . --file scripts/benchmarks/core-skills-smoke.mjs --args '<config> <output.json> [comma-separated case IDs]'`.

- Initial: retained failures from the1600-token output cap and JSON formatting. The interrupted first runner was replaced after fixing the evaluation harness.
- Development: seven domains; every case selected its matching skill. Architecture/review included formatting failures, preserved raw responses, and semantic issues noted below.
- Rechecks: architecture, review, testing, tool selection and diagnostics after targeted guidance corrections;3200-token output allowance. Structured-output warnings are separate from semantic review.
- UI: booking-screen design brief; real ui-ux-design and validation-reference loads, preserved brand/framework, addressed the five supplied UX defects, and did not claim screenshot/contrast validation.

Manual review: implementation produced the minimal inclusive-range repair; after inspecting the generated function it passed five independent execution checks. Review identified the tenant-key authorization defect. Testing covered ambiguous payment outcomes, duplicate effects and concurrency, with planned versus executed evidence distinguished. Tool selection picked calculation, clock and impact analysis and stated that schemas must be discovered. Services correctly identified missing host management despite full permission. Diagnostics rejected process count as evidence of host CPU usage.

Known limitations: architecture still made unmeasured capacity claims; review retained optional/conditional secondary findings; some diagnostic command suggestions were not verified against installed help. Skill prompts improve guidance but do not guarantee correctness. Generic read-only controller reviews did not consistently load a skill automatically; explicit skill invocation did load it. No claim of automatic selection reliability, accessibility compliance, improved benchmark intelligence or reduced production token usage is made.
