Cover finance/data, operations, software analysis, architecture/security and business/document workflows. Use supplied evidence, not unverifiable live facts. Freeze prompts and hidden grading hashes before inference; no answering-model involvement in authoring solutions.
2. Reuse the existing real SessionController/raw_direct paired harness in isolated workspaces. Same Qwen stable model and64K services, frozen deployed configuration, alternating arm order,300second common deadline. Preserve actual Codali routing/output policy; disclose asymmetries. No tuning during scored runs.
3. Run all100 attempts, preserving errors and first-attempt results. Validate reference answers and deliberately wrong outputs against independent checks. Score each job out of100 (five equally weighted criteria); absent/error answers earn zero. Report format compliance separately from semantic checks where extractable.
4. Publish all50 paired scores, equal-weight arithmetic means, differences, latency/token ratios and tool-use evidence. Include scope limits: fresh data cannot prove novel task types; this is a single-run synthetic workplace snapshot, not universal intelligence or autonomous delivery qualification. Commit reproducible scripts, frozen corpus, results and methodology. No npm publication.
