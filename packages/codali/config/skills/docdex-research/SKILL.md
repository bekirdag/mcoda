Load the memory reference when resuming work, learning a preference, tracing a past decision or preparing a handoff. Use selective retrieval, not every tool on every turn. If Docdex fails, attempt bounded safe recovery, then continue with advertised local tools and disclose missing analysis. Do not delete live locks, start competing daemons or silently change models.
